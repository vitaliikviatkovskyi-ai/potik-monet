# Потік монет

Навчальний вебпроєкт із дисципліни «Веб розробка та дизайн».
Автор: Квятковський В. М., група ПП-23.

## Можливості

- Розрахунок прогнозованого строку накопичення фінансової цілі.
- Сторінки цілей, результатів, спільного перегляду та прикладу цілі.
- Адаптивний лендинг із відео, картою та інформером курсів НБУ.

## Інструменти

HTML, CSS, JavaScript, Git, GitHub і Visual Studio Code.
Сторінки використовують зовнішні ресурси Tailwind CDN, Google Fonts,
Font Awesome, YouTube, Google Maps та API НБУ, тому потребують інтернету.

## Локальний запуск

Відкрити папку у VS Code і запустити `index.html` через Live Server.
Або, якщо встановлено Python, виконати в папці проєкту:

```sh
python -m http.server 8000
```

Відкрити `http://localhost:8000` у браузері.

## Структура

- `index.html` — головна сторінка.
- `result.html`, `goals.html`, `shared.html`, `demo-goal.html` — додаткові сторінки.
- `css/`, `js/`, `assets/` — стилі, сценарії та графічні ресурси.

## Робота зі змінами

Перед початком роботи отримати зміни командою `git pull`.
Нові зміни виконувати в окремій гілці, переглядати через `git diff`,
додавати через `git add` і зберігати змістовним комітом.
Назви комітів: `feat:`, `fix:`, `docs:`, `chore:`.

## Публікація

GitHub Pages: гілка `main`, папка `/ (root)`.
Netlify: папка публікації `.`, команда збірки не потрібна.
Адреси опублікованих сайтів додаються після підтвердження деплою.
