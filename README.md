# 🌊 Потік монет — Симулятор та калькулятор фінансових цілей

**«Потік монет»** — це інтерактивний вебдодаток для моделювання та розрахунку строків досягнення фінансових цілей (купівля авто, нерухомості, створення резервного фонду тощо). Проєкт створено в рамках лабораторної роботи з вебдизайну та розробки.

---

## 🛠 Технології
* **HTML5** — семантична верстка та компонентна структура
* **Tailwind CSS** — утилітарні класи, Mobile First підхід та адаптивна Grid-сітка
* **JavaScript (ES6)** — калькулятор накопичень та інтерактивність
* **Font Awesome / Montserrat** — іконки та фірмова типографіка
* **Netlify** — хмарний деплой та хостинг

---

## 📱 Основні сторінки проєкту
* `index.html` — Головна сторінка з симулятором, описом можливостей, FAQ та локацією.
* `goals.html` — Особистий кабінет з переліком цілей та параметрами накопичень.
* `demo-goal.html` — Інтерактивний демонстраційний приклад цілі (Ferrari F8 Tributo) та каталог шаблонів.
* `result.html` — Детальний розрахунок горизонту накопичень та помісячний графік.
