# Спільна робота над проєктом

Перед роботою перевірте git status, збережіть локальні зміни та виконайте git pull --ff-only origin main.

Кожна зміна виконується в окремій гілці й перевіряється перед злиттям.

## Правила

1. Створіть гілку через git switch -c feature/назва.
2. Збережіть зміни змістовним комітом.
3. Перед злиттям перегляньте git diff і перевірте сторінку.
4. Якщо виник конфлікт, узгодьте підсумковий текст, видаліть маркери конфлікту, виконайте git add і git commit.

Для ЛР №8 конфлікт у цьому файлі навмисно відтворено та вирішено локально одним автором. Спільна робота з одногрупниками цим прикладом не підтверджується.
